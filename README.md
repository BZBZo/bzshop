# 소개
MSA 아키텍처를 적용한, BZ#(비지샵)은 소셜커머스의 핵심인 공동구매와 SNS 기반 홍보•참여 요소를 결합한, 쌍방향 커머스 플랫폼입니다.   

# 주요 기능
**공동구매** : 인원수 기반 할인률 적용하여 공구 가능 여부와 함께 상품 등록, 공구 가능 상품 누구나 모집 개설 가능   
**광고등록** : 판매상품 링크와 게시 기간 지정하여 광고 등록   
**0OTD게시판** : 게시물 작성, 좋아요, 연관 상품 태깅 및 연결, 사용자 피드 연결   
**일반 쇼핑 기능** : 장바구니, 결제, 리뷰, 사용자 피드 방문 등
